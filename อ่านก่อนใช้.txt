วิธีเปิด (macOS)
------------------------------------------------------------
ง่ายที่สุด: ดับเบิลคลิก BirdNET eBird.app ในโฟลเดอร์ BirdNET-eBird-mac
   ต้องเก็บแอปไว้ในโฟลเดอร์เดียวกับ python/ และ app/

วิธีสำรอง:
1. แตกไฟล์ ZIP ทั้งอันก่อน (ดับเบิลคลิกที่ .zip)
2. เก็บทั้งโฟลเดอร์ BirdNET-eBird ไว้ด้วยกัน อย่าแยกไฟล์
3. ครั้งแรก: คลิกขวา (หรือ Control-click) ที่ BirdNET-eBird.command
   แล้วเลือก Open > Open  (จำเป็นครั้งแรกเพราะแอปยังไม่ได้ notarize)
   ครั้งต่อไปดับเบิลคลิกได้เลย
   ถ้าขึ้นว่า "damaged / cannot be opened" ให้เปิด Terminal พิมพ์:
       xattr -dr com.apple.quarantine /path/to/BirdNET-eBird
ต้องลงอะไรเพิ่มไหม? ไม่ต้อง มี Python และ ffmpeg/ffprobe มาให้ครบในโฟลเดอร์นี้
   อ่านได้ทั้ง WAV, MP3, FLAC, M4A (ไฟล์จากมือถือ), OGG, AIFF

ใช้งาน:
1. เปิดแอป แล้วคลิก "Choose file and start" หรือ "Choose folder and start"
   แอปจะตรวจข้อมูลไฟล์และเริ่มวิเคราะห์เอง ถ้าไม่มีวันที่หรือพิกัดใน metadata
   จะเปิดหน้าต่างให้กรอกข้อมูลจริงก่อนเริ่ม (วันที่เป็น YYYY-MM-DD)
   ถ้าทราบเวลาเริ่มบันทึก ให้กรอก HH:MM เพื่อให้เวลาแต่ละคลิปถูกต้อง
   หากเลือกหลายไฟล์ วันที่/พิกัดที่กรอกจะใช้กับทุกไฟล์ ต้องยืนยันว่าเป็นชุดเดียวกัน
   ถ้าคนละวันหรือคนละจุด ให้แยกประมวลผล
2. เมื่อวิเคราะห์เสร็จและมีผลลัพธ์วันเดียว แอปจะเปิดแท็บ "Review clips" ให้
   หากมีหลายวัน ให้เปิดโฟลเดอร์ผลลัพธ์แล้วเลือก summary.xlsx ของวันที่ต้องการ
   เลือกคลิป กด ▶ Play ฟังเสียง
   กด Spectrogram ดูภาพเสียง แล้วแก้ชื่อชนิดนกและให้คะแนน Audio quality 1–5 ด้วยคน
   กด ✓ Approve → Ready เพื่อคัดลอกเฉพาะคลิปที่ตรวจแล้วไปโฟลเดอร์ Ready/
   หรือกด Reject / Keep pending; R0 ในคลิปต้นทาง = ยังไม่ตรวจ
   ค่า AI confidence band เป็นเพียงค่าของโมเดล ไม่ใช่คะแนนคุณภาพเสียง
3. แท็บ "Advanced settings" ใช้ปรับเกณฑ์และรายละเอียดอื่นเมื่อจำเป็น
   แท็บ "Merge clips" ใช้รวมคลิปของนกตัวเดียวกันที่ตรวจสอบแล้วเท่านั้น
   ตัวเลือก Keep continuous ในแท็บขั้นสูงเก็บเสียงตั้งแต่การพบครั้งแรกถึงครั้งสุดท้าย
   ของแต่ละชนิดไว้ต่อเนื่อง เหมาะเมื่อยืนยันว่าเป็นนกตัวเดียวกัน
   ช่วงต่อเนื่องขนาดใหญ่มากจะให้เตรียมในโปรแกรมแก้เสียงแทน เพื่อไม่ให้หน่วยความจำเต็ม

ผลลัพธ์เก็บไฟล์ต้นฉบับไว้เหมือนเดิม การรันซ้ำด้วย force redo จะสร้างคลิป
และสรุปใหม่ พร้อมตั้งสถานะการตรวจกลับเป็น Pending
เลือกไฟล์เดิมซ้ำโดยไม่ติ๊ก force redo จะเปิดผลเดิมให้ และเก็บผลตรวจที่ทำไว้
ปิดโปรแกรมระหว่างวิเคราะห์ได้ ไฟล์ที่เสร็จแล้วถูกบันทึกไว้ รันใหม่จะทำต่อจากไฟล์ที่เหลือ
เวลาใน metadata ที่เป็น UTC (เช่นไฟล์ m4a จากมือถือ) จะแปลงเป็นเวลาตาม time zone
ที่ตั้งไว้ในเครื่อง Mac (System Settings > General > Date & Time) ตั้งให้ตรงกับจุดที่บันทึก

------------------------------------------------------------
How to open (macOS)
------------------------------------------------------------
Double-click BirdNET eBird.app inside the BirdNET-eBird-mac folder.
Keep the app in that folder with python/ and app/.

Alternative launcher:
1. Unzip the whole archive first.
2. Keep the BirdNET-eBird folder together.
3. First run: right-click (Control-click) BirdNET-eBird.command > Open > Open
   (needed once because the app isn't notarized). After that, double-click.
   If it says "damaged / cannot be opened", open Terminal and run:
       xattr -dr com.apple.quarantine /path/to/BirdNET-eBird
Nothing else to install: Python and ffmpeg/ffprobe are included. Supported
input: WAV, MP3, FLAC, M4A (phone recordings), OGG, AIFF.

On the Start tab, click "Choose file and start" or "Choose folder and start". The app checks metadata and
starts automatically. If the recording date or coordinates are missing, it asks
for the real values in one dialog before analysis. Enter the date as YYYY-MM-DD
and the start time (HH:MM) when known. File timestamps may not be the actual
recording start. The program stops before loading BirdNET if required details
are missing.
For a folder with multiple files, a manually entered Date applies to every
file. Confirm they share that date, or process the dates separately. In CLI
mode, add --same-date-for-all after checking the files.

Review each result in the Review clips tab: listen, inspect the spectrogram, correct
the species, and assign a human audio-quality rating. Only approved clips are
copied to Ready/. BirdNET confidence is not an audio-quality rating.
Selecting an already-processed file again (without force redo) opens the
existing results and keeps your reviews. Closing the app during analysis is
safe: finished files are saved and the next run continues with the rest.
UTC timestamps in metadata (e.g. phone m4a files) are converted to the Mac's
time zone (System Settings > General > Date & Time); set it to where you recorded.
Very long continuous spans may need a dedicated audio editor to avoid running
out of memory.

------------------------------------------------------------
Included components
------------------------------------------------------------
 - Python 3.12 (python-build-standalone) with Tcl/Tk 9
 - BirdNET via birdnetlib, running on LiteRT (ai-edge-litert) instead of
   TensorFlow; the model is CC BY-NC-SA 4.0 (non-commercial use)
 - ffmpeg/ffprobe for audio formats and metadata. They are included in a built
   bundle; tools/build_ffmpeg.sh can build portable copies on macOS.

Please upload to eBird / Macaulay Library
------------------------------------------------------------
